# Wiki 使用规则

所有写入 `content/wiki/` 的内容必须遵守以下规则（Agent 同样遵守）：

1. 写入前先搜索是否已有同义页面；
2. 优先更新已有页面，不重复创建；
3. 区分「我的原话」「Agent 总结」「外部来源」；
4. 不把未经确认的 Agent 推断写成我的观点；
5. 每页包含 `updated` 和 `tags`，日期格式统一为 `YYYY-MM-DD`；
6. 新页面至少连接一个已有页面（仅当已有页面存在时适用）；
7. 修改 Wiki 也必须经过 `git diff` 审查。

标注方式：

- **我的原话**：用 `>` 引用块标注来源；
- **Agent 总结**：不加标记；
- **外部来源**：必须附链接；
- **未经确认的推断**：不写入。
