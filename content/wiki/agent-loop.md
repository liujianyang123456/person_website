# Agent Loop 与我的理解

> **我的原话**（课堂笔记，2026-10）：
> 「Agent Loop 就是『接收目标 → 思考 → 调用工具 → 观察结果 → 再决定下一步』的循环，
> 一直转到任务完成或者需要人来拍板。」

Agent 总结：Agent Loop（智能体循环）是 Agent 区别于单轮问答的核心机制：

1. 模型根据当前目标决定**下一个动作**（回复、调用工具、请求确认）；
2. 工具返回的**观察结果**被放回上下文，成为下一轮决策的依据；
3. 循环在「任务完成」「达到步数上限」「需要人工介入」时结束。

在本项目里的对应关系：

- 提出需求 → Agent 修改文件（行动）→ 构建与检查脚本（观察）→
  失败就修复、通过就提交（决策），这就是一个课程尺度的 Agent Loop；
- `scripts/build_all.py` 的各种检查就是这个循环里的「观察器」，
  让错误在提交前暴露，而不是等部署后才发现。
