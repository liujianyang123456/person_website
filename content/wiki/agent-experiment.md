# 我的第一次 Agent 实验

> **我的原话**（整理自 2026-09-02 的博客[《我的第一次 Agent 实验》](../posts/hello-agent.html)）：
> 「和 Agent 协作的关键不是把句子写得很长，而是给出清晰的目标、约束和验收标准。」

Agent 总结：这是我在课程 Step 1 学到的第一个方法——一个可执行的需求至少要包含：

1. **用户是谁**：一名江苏警官学院大四数据警务专业学生；
2. **做什么**：只使用 HTML 和 CSS 的个人首页；
3. **内容**：姓名、学校、专业、自我介绍、三个兴趣方向和邮箱；
4. **约束**：不引入框架、不加载外部库、正文最大宽度 800px；
5. **怎样算完成**：能打开、信息可见、语义化标签、CSS 单独文件。

核心结论：**需求越可验证，Agent 越少自由发挥。**
