# 我的第一次 Agent 实验

我发现，和 Agent 协作的关键不是把句子写得很长，而是给出清晰的目标、约束和验收标准。

## 今天的收获

- 先说明用户是谁；
- 再说明页面应该包含什么；
- 最后说明如何判断完成。

## 一次真实的对比

一开始我只会说「帮我做一个好看的个人网站」，结果 Agent 自由发挥，
做出来的东西既不像我，也没法验收。

后来我把需求改成：用户是谁、内容有哪些、技术约束是什么、完成标准有几条。
Agent 的输出立刻稳定了下来。**需求越可验证，Agent 越少自由发挥。**
