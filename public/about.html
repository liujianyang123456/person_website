这个网站是怎么来的

它不是一次性写完的，而是按课程路线一步步长出来的，每一步都留下 Git 提交和验收记录：

  • Step 1-2：最小首页；纳入 Git 管理，用 GitHub Pages 自动部署上线；
  • Step 3：菜单栏与多页面（首页 / 关于我 / 博客 / 论文 / Wiki）；
  • Step 4：Markdown 博客，由脚本从 content/posts 自动生成页面；
  • Step 5：发布自己的 RSS 2.0 订阅源 feed.xml；
  • Step 6：RSS 阅读器，订阅外部内容并划定信任边界；
  • Step 7：用自定义 Skill 收集 arXiv 最新论文；
  • Step 8：文件化个人 Wiki，支持 [[双向链接]]；
  • Step 9：Wiki 检索与「只依据证据」的问答（RAG）；
  • Step 10：网站状态面板，让 Agent 的工作可观测。

项目规则写在仓库根目录的 AGENTS.md，构建入口是 python scripts/build_all.py。
